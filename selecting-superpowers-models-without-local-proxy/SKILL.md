---
name: selecting-superpowers-models-without-local-proxy
description: Use when starting a new task from the Superpowers framework when not connected to a local LLM proxy
---

When starting a new task from the Superpowers framework in Claude Code, select the model from the list below

* brainstorming: opus
* finishing-a-development-branch: haiku
* subagent-driven-development: sonnet for the controller and implementers, opus for the final review
* using-git-worktrees: haiku
* writing-plans: opus
* dispatching-parallel-agents: sonnet for the dispatcher, each subagent sized to its own task
* receiving-code-review: sonnet
* systematic-debugging: opus
* writing-skills: sonnet for drafting, pressure tests on the model the skill will run on
* executing-plans: sonnet
* requesting-code-review: opus for whole-branch reviews, sonnet for per-task reviews
* test-driven-development: sonnet
* verification-before-completion: sonnet
